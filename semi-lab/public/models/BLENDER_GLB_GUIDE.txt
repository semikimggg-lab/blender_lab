SEMI LAB Blender GLB 등록 안내

1. Blender에서 부품을 컬렉션 또는 부모 Empty 단위로 정리합니다.
   예: 로봇 / 베이스 / 툴 / 작업대. 오브젝트 이름은 구체적으로 지정합니다.
2. 파일 > 내보내기 > glTF 2.0, 형식 GLB를 선택합니다.
3. Full Collection Hierarchy, Custom Properties, Animation을 켭니다.
   Blender 버전에 따라 옵션 위치가 다릅니다.
4. 텍스처는 GLB 안에 포함하고 Draco/Meshopt/KTX2 압축은 끕니다.
5. 모델 탐색 화면 /explorer에서 '내 .glb 새로등록'를 누릅니다.
6. GLB 파일을 선택한 뒤 그룹, 애니메이션과 분해 동작을 확인합니다.
7. 관리자는 모델 제목과 각 그룹의 표시 이름, 기능 설명, URL을 입력할 수 있습니다.
8. '사이트에 모델 저장'을 누르면 다른 PC에서도 열 수 있는 모델 주소가 생깁니다.
9. 저장 후 설명을 변경하면 '설명과 URL 저장'을 누릅니다.
10. 홈 > 메뉴·설비 관리 > 설비 추가에서 저장된 모델 주소를 연결합니다.

입력 파일: 자체 포함 GLB 2.0, 최대 20MB, 전체 노드 최대 3000개,
선택 가능한 메시/그룹 노드 최대 500개.
'내 .glb 새로등록'만으로 서버에 업로드되지는 않습니다.
사이트 저장은 소유자만 할 수 있으며 사이트의 기존 접근 권한을 따릅니다.
기존 모델 파일 교체 기능 대신 새 버전 GLB는 새 모델로 등록합니다.

그룹 사용자 속성(선택 사항):
 partId: 안정적인 부품 ID
 description: 기능 설명
 infoUrl: https:// 또는 사이트 내부 / 경로
컬렉션 속성의 내보내기 동작은 Blender 버전에 따라 다를 수 있습니다.
확실한 메타데이터 연결이 필요하면 그룹 부모 Empty에 사용자 속성을 넣으세요.
전체 계층이 빠진 GLB에서는 원래 컬렉션을 복원할 수 없습니다.
컬렉션 다중 소속/인스턴스는 GLB의 단일 부모 노드 구조에 맞춰 변환됩니다.

GLB 안에 애니메이션이 있어야 재생할 수 있습니다.
Blender의 IK/제약/시뮬레이션은 지원되는 애니메이션으로 베이크해서 내보내세요.
복잡한 스키닝과 뼈 계층에서는 분해 그룹을 조립체 부모로 분리해 확인하세요.
분해 이동은 그룹 사이에 간격을 더하며 원본 GLB 파일은 변경하지 않습니다.

공식 참고:
https://docs.blender.org/manual/en/latest/addons/import_export/scene_gltf2.html

저장 모델 정리: 카테고리·폴더 관리에서 상위 카테고리와 하위 폴더를 만든 뒤, 모델의 저장할 폴더를 지정하고 모델 정보·설명 저장을 누르세요.
모델 삭제는 관리자만 가능하며 휴지통에서 복원할 수 있습니다.
