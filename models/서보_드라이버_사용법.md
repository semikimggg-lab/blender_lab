# 서보 드라이버 Geometry Nodes 모델

`servo_driver_geometry_nodes.blend`를 열면 드라이버 팩이 선택되어 있습니다. 오른쪽 렌치(Modifiers)의 Servo controls에서 값을 조절합니다.

- Target position (mm): 원점부터 목표 이동 거리. 기구가 허용하는 범위로 자동 제한합니다.
- Speed limit (rpm): 최대 회전 속도. 짧은 이동에서는 이 속도에 도달하기 전에 감속합니다.
- Accel / decel (s): 설정 속도까지의 가속 시간. 감속도 같은 기울기를 사용합니다.
- Screw length (mm): 스크류 길이. 가이드·베이스·끝 지지대도 따라 변경됩니다.
- Lead (mm/rev): 1회전당 이동 거리. 나선 형상과 이동 계산에 함께 반영합니다.

프레임 1이 원점입니다. 값을 바꾸고 처음부터 스페이스바로 재생합니다. 기본 설정은 160mm, 120rpm, 가감속 0.8초, 길이 560mm, 리드 20mm입니다. 4.8초에 이동을 완료합니다. 기본 타임라인은 12초입니다. 낮은 속도 등으로 이동 시간이 길어지면 끝 프레임을 늘려야 합니다. 재생은 원점 기준의 미리 계산된 동작이며 실제 드라이버처럼 현재 위치에서 명령을 이어받는 제어기는 아닙니다.

Geometry Nodes 그룹의 출력은 Geometry, Actual position (mm), Screw angle (deg), Actual speed (rpm), Move duration (s)입니다. 계산값은 형상의 actual_position_mm, screw_angle_deg, actual_speed_rpm, move_duration_s 속성으로도 기록됩니다. Spreadsheet에서 확인할 수 있습니다.

현재는 Blender 안에서 조절하는 교육용 모델입니다. 실제 드라이버 통신·서보 제어 루프·토크·충돌·제조용 나사 형상은 포함하지 않습니다. 웹사이트 연결은 아직 적용하지 않았습니다. 원본 servo_screw_demo.blend는 보존했습니다.

검증: 원점, 가속, 정속, 목표 정지, 이동 0, 짧은 삼각 속도 이동, 기구 이동 한계, 리드 변경에 따른 회전량과 형상 갱신.
