# SEMI LAB 작업 인계 · 2026-11-04

운영 주소: https://semi-lab-explorer-20261028.semikim111.chatgpt.site/

## 사용법
- 관리자로 로그인한 뒤 저장 모델을 하위 폴더 또는 미분류로 드래그하면 즉시 위치가 저장됩니다.
- 모델 우클릭 → 다른 폴더로 이동. 카테고리 우클릭 → 여기에 새 폴더 만들기.
- 빈 목록 우클릭 → 새 상위 카테고리 만들기. 폴더는 상위 카테고리 / 하위 폴더의 2단계입니다.
- 파트 선택 → 설명 자료의 + 자료 추가 → 제목 및 HTTPS URL 또는 사이트 내부 경로 입력 → 모델 정보·설명 저장.
- − 버튼은 해당 자료 한 개만 제거합니다. 제거한 뒤에도 저장 버튼을 눌러야 반영됩니다.
- 자료는 파트당 최대 20개. 기존 단일 URL은 관련 자료라는 제목으로 이어집니다.
- 모델 삭제와 폴더 변경은 서버에서 관리자 권한을 확인합니다. 삭제한 모델은 관리자 휴지통에서 복원합니다.

## 수정 위치
- 메인 화면 구성: content/explorer.html
- 디자인: public/explorer.css
- 3D 모델, 파트 설명과 자료: src/explorer/app.js
- 저장 모델 폴더, 우클릭, 이동: src/explorer/catalog.js
- 자료 검증: lib/model-policy.mjs
- 모델 저장 / 폴더 이동 / 삭제 API: app/api/models/[id]/route.ts
- 상위 메뉴: public/site-navigation.js
- DB 구조: db/schema.ts 와 drizzle 마이그레이션

## 회사 PC에서
Node.js 24 설치 후 semi-lab 폴더에서 npm ci, npm run dev.
자체 DB/R2 설정은 README.md와 .openai/hosting.json을 참고합니다.
.env, .dev.vars, 로그인 토큰은 백업 또는 GitHub에 포함하지 않습니다.
실제 운영 모델과 설명은 서버 DB/R2에 저장되어 소스만 복사하면 자동 복원되지는 않습니다.
Blender에서 변경한 뒤 GLB로 다시 내보내고 웹에 등록합니다. Geometry Nodes 자체는 GLB로 실행되지 않습니다.

## 재현 요청 프롬프트
기존 SEMI LAB 사이트의 Blender 모델 탐색을 메인으로 유지한다. 원래 GLB 이름과 계층, 애니메이션을 보존하고 컬렉션 폴더와 세부 파트를 선택하게 한다. 선택한 파트는 선명하게, 나머지는 반투명으로 표시한다. 저장 모델은 상위 카테고리와 하위 폴더로 정리하며 관리자만 폴더 생성·이름 변경·모델 이동·삭제가 가능해야 한다. 저장 모델을 드래그하여 하위 폴더 또는 미분류로 즉시 이동하고 우클릭 메뉴로 새 폴더 생성과 이동을 제공한다. 모델 이동 API는 버전을 확인하고 폴더 위치만 수정하여 설명 편집을 덮어쓰지 않는다. 파트별 설명 자료를 제목과 URL 배열로 저장하고 +와 −로 추가·삭제한다. 기존 단일 URL과 JSON 가져오기 및 내보내기는 호환한다. unsafe URL과 과도한 입력을 서버에서 거절한다. 실제 운영 모델로 삭제 테스트하지 말고 로컬 테스트를 사용한다. 테스트와 빌드 후 기존 비공개 공유 설정을 유지하여 배포하고 GitHub와 로컬 백업을 갱신한다.
